# 许静｜外观与换装

许静 33 岁，设定身高 **168 厘米**。她的身形中等偏瘦，平时偶尔跟跑团跑步。黑发侧分，发梢齐下颌。额头缓缓向后，眼位到下颌的距离略长，眉线平，鼻梁适度挺直。放松时双眼和嘴角自然平衡。

她父亲许建军在北京东城安定门附近长大，母亲邱丽萍在北京朝阳团结湖一带长大。造型设定里，许静的额头轮廓和较长的中下庭像母亲，平眉、平直鼻梁像父亲。外观、身高及具体家族相似处均为虚构设定。
