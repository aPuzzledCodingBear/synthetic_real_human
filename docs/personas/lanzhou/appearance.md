# 韩志远｜外观与换装

韩志远 32 岁，设定身高 **176 厘米**。头脸轮廓偏宽方，脸颊转角柔和，鼻尖短圆，嘴唇略饱满。黑色短发修得利落，肩较宽。自然站立时双肩放松，眼睑和嘴角起落平稳。

他父亲韩崇义在兰州榆中和平一带长大，母亲魏秀梅在兰州七里河晏家坪一带长大。造型设定里，韩志远偏宽方的头脸和柔和的脸颊轮廓像父亲，短圆的鼻尖和饱满的嘴唇像母亲。外观、身高及具体家族相似处均为虚构设定。
