# 顾宁｜外观与换装

顾宁 30 岁，设定身高 **164 厘米**。下颌轮廓自然圆润，脸颊略饱满，眉色深，眉形清楚。黑发松松束成低马尾，耳边留少量碎发。她长期练 CrossFit，肩背和腿部有自然的训练痕迹，体态结实。上述外观和身高为虚构造型设定。

## 家里人像谁

按虚构造型设定，顾宁下半张脸短而圆润，像奶奶罗秀珍，眉形清楚偏直，像母亲施慧琴。父亲家早年从闸北搬到甘泉，母亲在嘉定南翔长大。相貌上的参照来自这两位具体的家人。[家族经历](background.md)
