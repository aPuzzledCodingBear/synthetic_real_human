# 林文斌｜外观与换装

林文斌 31 岁，设定身高 **172 厘米**。脸型偏中长，轮廓略方，表情变化在眉眼和嘴角看得出来。黑色短发自然微卷，偏分，上唇和下巴有轻微胡茬。体型中等偏精瘦，站立时肩膀自然放松。上述外观和身高为虚构造型设定。

## 家里人像谁

按虚构造型设定，林文斌偏长、略方的脸型像父亲林建新，短发的自然卷度像母亲陈惠芳。父亲在闽江南岸的仓山长大，母亲在台江苍霞长大。相貌上的参照来自这两位具体的家人。[家族经历](background.md)
